## Two findings the running system makes concrete

**C1 is live in API responses.** All 32 patients above are synthetic
phantoms. The API labels 29 of them `OASIS` or `ADNI` and the remaining 3
`Clinic`. Nothing in the payload marks any of it as synthetic. The
`/openapi.json` description also still advertises a "Mamdani fuzzy inference
engine" (C10).

**C6 and C10 are visible in a single record.** A real seeded scan returns:

```json
{"stage": "AD", "confidence": 53.2, "uncertainty": 93.6, "needsReview": true}
```

A clinician reading that sees 53.2% confidence *and* 93.6% uncertainty on
the same result. They are not complements and not on a shared scale —
`confidence` is the winning stage's normalised share, `uncertainty` is
`(1 − top-two margin) × 100`. Both are rendered as percentages in the UI.
Half the seeded cohort (16/32) trips the review flag, which suggests the
45.0 threshold is not calibrated to anything.

Neither was changed in Phase 0, per the flag-don't-fix rule.
